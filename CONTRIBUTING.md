# Contribution Guidelines

Thank you for helping make **Awesome Network Automation AI** better! Please take a moment to review these guidelines before submitting.

## How to contribute

1. Fork this repository.
2. Add your resource to the most appropriate section in `README.md`.
3. Open a pull request with a clear title and a short note on why the resource belongs here.

You can also [open an issue](../../issues/new) to suggest a resource if you'd rather not open a PR.

## Format

Add each resource as a single bullet under the relevant section, kept in the following format:

```markdown
- [Resource Name](https://example.com) - A short description that ends with a period.
```

Guidelines for entries:

- **Order** entries alphabetically within their section where practical.
- **Descriptions** should be concise (ideally one line), start with a capital letter, and end with a period.
- **No marketing language** — describe what the resource *is* and *does*, not how great it is.
- **Use HTTPS** links where available, and link to the canonical source.

## What makes a good resource

To keep the list high quality, resources should be:

- **Relevant** — genuinely at the intersection of AI/ML/LLMs and network automation.
- **Useful** — something a practitioner would actually benefit from.
- **Accessible** — publicly reachable (paywalled content is okay if clearly the best of its kind, but note it).
- **Maintained** — for tools and projects, prefer those that are actively maintained.

## Quality checks

Before submitting, please make sure:

- [ ] The link works and points to the correct resource.
- [ ] The entry is in the right section and follows the format above.
- [ ] There are no duplicate entries.
- [ ] Spelling and grammar are correct.

## Removing resources

If a resource becomes unmaintained, the link rots, or it's no longer relevant, please open a PR or issue to have it removed.

Thanks again for contributing! 🎉
